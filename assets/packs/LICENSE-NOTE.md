# Origine delle immagini delle bustine

`lob-front.png`, `mrd-front.png`, `rotd-front.png` e `side.png` sono illustrazioni **originali**,
create per questo progetto (gradienti, forme geometriche generiche, testo) — non sono copie né
elaborazioni delle box/bustine reali di Konami. Nessun artwork o logo Konami è stato usato, in linea
con i vincoli di copyright già seguiti per le immagini carta (vedi README principale).
